# ILA 3-1: Applying the Four Pillars of OOP
## Sari-Sari Store Inventory System

### 1. Encapsulation
Encapsulation allows all properties of an object to be grouped under one. In this case, a product can have its name, price, and quantity under one variable which is the product. This helps the efficiency and storage of information inside the inventory system.

### 2. Abstraction
Abstraction helps in handling the data by focusing on important functions and ignoring unnecessary ones. For example, in this system, the price can change over time, and the function for this doesn't need other variables except for the product's previous price and new price or the rate of change.

### 3. Inheritance
In this inventory system, inheritance can be applied in asking for required inputs of the products. Passing down the functions to all products provides efficiency. 

### 4. Polymorphism
Polymorphism can be used in managing data since the products have different values in their properties. For example, the change in the availability is different for all products.

## Reflection
In my opinion, the best to use among the four pillars is encapsulation. Considering the type of system that this has, encapsulation is efficient to use in an inventory. It groups all properties of an object under a single one, providing easier storing and updating of data.
