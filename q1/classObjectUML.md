# SG4 - Understanding Classes and Objects
## Movies
## This class is an inventory of the user's favorite films. It stores the title, director, genre of the movie and the user's rating in a single object, and contains few methods including edit(), remove(object: class), and display().
## Properties
| Property | Data Type | Description |
|---|---|---|
| Title | String | Title of the movie |
| Director | String | Name of the director |
| Genre | String | Classification of genre |
| Ratings | Integer | Personal rating | 
## Methods
| Method | Description |
|---|---|
| add() | Adds objects in the inventory |
| edit() | Edits the data of the properties of the objects |
| remove(object: class) | Enables to remove an object |
| display() | Displays the stored information of the objects |

## Design Explanation
### Why did you choose this class? 
#### I was inspired by an existing app that tracks movies and asks for rating, to create an inventory for movies.
### Which property is the most important? Why?
#### The most important property is the title because it names the object which helps in the identification of each one.
### Which method is the most useful? Why?
#### The most useful method is add() since it performs the most important process in adding information to be stored in the inventory.
